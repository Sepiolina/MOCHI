Pre-release of MOCHI 1.0. The toolbar has two new buttons. Info shows the version on screen the way WinRAR's Info tab does: total folders and files, total size, packed size and the ratio, the size of the archive file, the compression it was written with, and the archive's comment. Scan runs a virus scanner you already have (Microsoft Defender on Windows, ClamAV on Ubuntu, or any program you choose) on a temporary copy of the version on screen and shows what the scanner said; a report with no threats is the scanner's answer, not a promise that the files are harmless. An archive can now have a comment: set it with Edit comment... in Info, or with mochi create and mochi append --comment, and read it with the new mochi comment command. Each version keeps the comment it had, and an encrypted archive cannot have one. Important: an archive that has a comment cannot be opened by earlier versions of MOCHI, which will say they need a newer version; archives without a comment are written exactly as before and open everywhere. Menus, windows and lists now move smoothly, and Settings, General has Animations (As the system, On or Off) for slower computers. The window has a more refined look, the list of versions opens inside the window, and the old Info item that shows the details pane is now called Details. On Windows, Settings, Performance can count a folder flush on a local NTFS drive as saved when an archive is created; it is off by default, so a new archive is still reported as unconfirmed unless you turn it on, and network drives and other file systems stay unconfirmed either way. Archives made by earlier versions open as before.
