Pre-release of MOCHI 1.0. Find in archives can now look for many file names at once: paste or type a list (one per line, or separated by commas, semicolons or tabs) and Find says which names were found, how often, and which were not; while some archives could not be searched it says "not found in what was searched" instead of just "not found". New options: Match case, Whole name only, Show files or folders only, and Search subfolders. There is no longer a limit on how many matches you can see: the list loads more as you scroll. Tick the matches you want, or tick all of them however many there are, and choose Retrieve to extract them from every archive they are in, into a new folder for each archive or all into one folder, keeping files that are already there or replacing them (the old ones go to the Recycle Bin or Trash). The archives are only read, never changed. On the command line, mochi find also takes several names (--name, repeatable, or --names-from FILE) and the same options (--match-case, --whole-name, --files-only, --folders-only, --no-subfolders); the plain mochi find PATTERN FOLDER form and its JSON are unchanged. Extracting a large selection is much faster. Archives made by earlier versions open as before.
